ANYISP-Scanner

Universal ANYISP Scanner for Termux.

🚀 One-Command Install & Run

Termux খুলে শুধু এটা paste করো:

curl -fsSL https://raw.githubusercontent.com/Hackershimul07/ANYISP-Scanner/main/install.sh | bash

Install শেষ হলে scanner চালাতে:

cd ANYISP-Scanner && ./run.sh

⚡ Install + Run একসাথে

curl -fsSL https://raw.githubusercontent.com/Hackershimul07/ANYISP-Scanner/main/install.sh | bash && cd ANYISP-Scanner && ./run.sh

🔄 Update

cd ~/ANYISP-Scanner && git pull && ./install.sh

📱 Requirements

- Android
- Termux
- Internet connection for initial installation/update
- Python 3

⚠️ Usage

শুধু নিজের বা অনুমোদিত network/system-এ scanner ব্যবহার করো।
